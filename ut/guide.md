# 사람 UT 진행 가이드

`ut/plan.md` 를 실제 진행용으로 정리한 문서예요. 진행하는 사람은 이 문서 하나만 보고 진행할 수 있어요.
참가자 한 명에 **약 30분**이 걸려요. 3명(P1, P2, P3)에게 같은 방식으로 진행해요.

---

## 1. 준비물

### 사람
| 역할 | 하는 일 |
|---|---|
| 진행 (1명) | 대본을 읽고, 과제를 주고, 질문해요. 도와주지 않아요. |
| 기록 (1명) | `ut/notes/P번호.md` 에 결과, 시간, 막힌 곳, 참가자가 한 말을 그대로 적어요. 시간도 재요. |

혼자 진행해야 하면 참가자의 동의를 받고 화면과 목소리를 녹음해 두었다가 나중에 기록지를 채워요.

### 기기와 파일
- [ ] 프로토타입 `design/prototype.html` 을 열 기기 (휴대폰 권장, 노트북이면 브라우저 창을 휴대폰 폭으로 좁혀요)
- [ ] 미리 한 번 열어서 처음부터 끝까지 눌러 보기 (화면이 뜨는지, 버튼이 눌리는지)
- [ ] 기록용 노트북 또는 종이, `ut/notes/P1.md`·`P2.md`·`P3.md`
- [ ] 시간 재는 도구 (휴대폰 스톱워치)
- [ ] 과제 카드 3장: 과제 문장을 한 장에 하나씩 인쇄하거나 적어 둔 종이 (아래 4장의 과제 문장 그대로)
- [ ] 쉬움 점수 카드 1장: "1 아주 어렵다 · 2 · 3 · 4 · 5 아주 쉽다"
- [ ] 녹음·녹화를 할 경우 녹음 앱 (참가자 동의를 받은 뒤에만)

### 참가자
| 번호 | 닮은 퍼소나 | 찾을 사람 |
|---|---|---|
| P1 | 이길잡 | 월급을 받는 사회초년생인데, 무엇부터 해야 할지 몰라 재테크를 미루고 있는 사람 |
| P2 | 김안전 | 원금이 줄어드는 게 걱정돼 예금·적금 말고는 손대지 않는 사람 (대학생도 괜찮아요) |
| P3 | 불규칙 수입 | 아르바이트·프리랜서처럼 달마다 수입이 달라 적금을 꾸준히 넣을 수 있을지 걱정되는 사람 |

공통 조건: 20대, 재테크를 아직 제대로 시작하지 못한 사람, **우리 팀원이 아니고 이 서비스를 본 적 없는 사람**.
참가자의 이름은 어디에도 적지 않아요. P1, P2, P3 번호로만 기록해요.

### 장소
- 조용하고 화면을 같이 볼 수 있는 자리. 진행은 참가자 옆, 기록은 참가자 뒤쪽 비스듬히 앉아 화면이 보이게 해요.

## 3. 진행할 때 지킬 것

### 꼭 하기
- 대본을 **그대로** 읽어요. 사람마다 말이 달라지면 결과를 비교할 수 없어요.
- 과제 문장은 읽어 준 뒤 과제 카드를 참가자 앞에 놓아 두어요. 다시 보고 싶을 때 볼 수 있게요.
- 참가자가 말을 멈추면 "지금 무슨 생각 하세요?" 라고 가볍게 물어요.
- 참가자가 질문하면 되묻기만 해요: "어떻게 하실 것 같아요?", "어떻게 생각하세요?"
- 기록하는 사람은 참가자가 한 말을 **고치지 말고 그대로** 적어요. 해석은 괄호에 따로 적어요.
- 참가자가 무언가를 누르기 전에 머뭇거린 곳, 같은 화면을 여러 번 오간 곳, 스크롤을 빨리 넘긴 곳을 적어요.

### 하지 않기
- **도와주지 않아요.** 어디를 누르라고 가리키거나, 고개를 끄덕이거나, "거의 다 왔어요" 같은 말을 하지 않아요.
- 화면 이름, 버튼 이름, 용어 뜻을 먼저 말하지 않아요. (예: "로드맵", "이미 했어요", "ISA는…")
- 참가자가 틀렸다고 말하거나 표정으로 드러내지 않아요. 막히면 서비스의 문제예요.
- 서비스를 설명하거나 변명하지 않아요. ("원래는 이렇게 하려고 만든 거예요" 금지)
- 오른쪽 위 '화면 목록' 버튼과 화면 아래 **점선으로 된 작은 버튼**은 팀 확인용이라 쓰지 않아요. 참가자가 누르려고 하면 "그건 저희 확인용이라 빼고 해 주세요"라고만 말해요.

### 막혔을 때
- 같은 곳에서 **3분** 넘게 막히면: "괜찮아요, 이 과제는 여기까지 할게요." 라고 말하고 다음 과제로 가요. 기록지에 '실패'와 막힌 화면을 적어요.
- 참가자가 "이거 맞아요?" 하고 정답을 확인하려 하면: "참가자님 생각대로 해 주시면 돼요."
- 참가자가 힘들어하거나 그만하고 싶어 하면 바로 멈춰요. 남은 과제는 건너뛰고 사후 질문으로 가도 돼요.
- 프로토타입이 멈추거나 이상하면: "잠시만요, 화면을 다시 띄울게요." 하고 새로 고친 뒤 그 과제를 처음부터 다시 해요. 기록지 '그 밖에 본 것'에 적어요.

### 결과 기록 기준
| 결과 | 기준 |
|---|---|
| 성공 | 도움 없이 성공 기준에 도착 |
| 도움받아 성공 | "어떻게 하실 것 같아요?" 외의 도움(힌트)을 받고 도착 |
| 실패 | 3분 넘게 막혀 멈추거나, 참가자가 포기하거나, 성공 기준에 닿지 못한 채 "다 했어요"라고 함 |

과제 2, 3에서 앞 단계를 '이미 했어요'로 넘긴 것은 성공으로 봐요.

## 4. 그대로 읽을 대본

> 굵은 글씨가 아닌 괄호 ( ) 는 진행하는 사람이 할 행동이에요. 읽지 않아요.

### 1) 인사
"안녕하세요, 시간 내 주셔서 감사해요. 오늘은 재테크를 처음 시작하는 사람을 돕는 '차근차근'이라는 모바일 서비스를 써 보실 거예요.

오늘 평가하는 건 이 서비스이지, 참가자님이 아니에요. 틀린 답은 없어요. 헷갈리거나 막히는 곳이 있다면 그건 서비스를 고쳐야 한다는 뜻이니, 오히려 저희에게 큰 도움이 돼요.

이 서비스는 아직 만드는 중이라 진짜 돈이 오가거나 상품에 가입되지는 않아요. 금액은 실제와 달라도 괜찮으니 편하게 넣어 보세요."

### 2) 동의
"진행하는 동안 옆에서 메모를 해도 괜찮을까요? 이름은 적지 않고 번호로만 기록해요."

(녹음·녹화를 하는 경우) "나중에 다시 보려고 화면과 목소리를 녹음해도 괜찮을까요? 팀 안에서만 보고 평가가 끝나면 지울게요."

"중간에 그만하고 싶으시면 언제든 말씀해 주세요."

(동의하지 않으면 녹음 없이 메모만 해요.)

### 3) 소리 내어 생각하기
"화면을 보면서 떠오르는 생각을 소리 내어 말해 주세요. '이게 무슨 뜻이지?', '여기를 누르면 될 것 같은데', '이건 좀 길다' 같은 말이요. 혼잣말하듯이 편하게 하시면 돼요.

제가 중간에 도와드리지는 않을 거예요. 혼자 쓰실 때 어떻게 하는지 보고 싶어서예요. 그래도 궁금한 건 편하게 말씀해 주세요.

그리고 오른쪽 위 '화면 목록' 버튼과, 화면 아래에 점선으로 된 작은 버튼은 저희 확인용이라 쓰지 않아요."

### 4) 사전 질문
"시작하기 전에 두 가지만 여쭤볼게요."

1. "지금 적금, 파킹통장, 주식 같은 재테크를 하고 있나요? 한다면 무엇을, 안 한다면 왜인가요?"
2. "금융 상품을 알아볼 때 가장 막히는 건 무엇인가요?"

### 5) 과제 시작 안내
"이제 상황을 하나 말씀드릴게요. 그 상황이라고 생각하고 서비스를 써 보세요. 다 됐다고 생각되면 '다 했어요'라고 말해 주세요."

### 6) 과제 1: 첫걸음 찾기
(시작 화면인지 확인 → 과제 카드 1을 놓고 → 스톱워치 시작)

"취업한 지 몇 달 됐어요. 월급이 들어오는데 통장에 그냥 쌓여만 있어요. 이 서비스로 나는 무엇부터 하면 되는지 알아보고, 오늘 바로 할 수 있는 첫 번째 일을 해 보세요."

(참가자가 '다 했어요'라고 하면 스톱워치 멈춤)

"방금 과제는 얼마나 쉬웠나요? 1은 아주 어렵다, 5는 아주 쉽다예요. 숫자로 말해 주세요."

"하나만 더 여쭤볼게요. 지금 이 서비스에서 참가자님이 해야 할 일은 뭐라고 생각하세요?"

> 기록용 성공 기준: 진단을 마치고 로드맵 0단계를 끝낸 뒤, 1단계 상세에서 '다 했어요'를 눌러 로드맵으로 돌아옴 + "지금 할 일은 ○○"이라고 말함

### 7) 과제 2: 수입이 들쭉날쭉할 때 적금 정하기
(프로토타입 **새로 고침** → 시작 화면 확인 → 과제 카드 2 → 스톱워치 시작)

"이번에는 다른 사람이 되어 볼게요. 처음부터 다시 시작해요.

프리랜서로 일해서 달마다 버는 돈이 달라요. 적금을 들어 보고 싶은데, 나에게 맞는 적금은 어떤 것이고 매달 얼마씩 넣으면 될지 정해 보세요."

(끝나면) "방금 과제는 얼마나 쉬웠나요? 1부터 5까지 숫자로 말해 주세요."

> 기록용 성공 기준: 수입 질문에서 '달마다 차이가 있어요'를 고르고, 적금 상세에서 납입 금액을 정해 체크한 뒤 '다 했어요' → 로드맵에서 2단계가 완료로 보임

### 8) 과제 3: 돈이 줄어드는 게 무서울 때 세금 혜택 알아보기
(프로토타입 **새로 고침** → 시작 화면 확인 → 과제 카드 3 → 스톱워치 시작)

"마지막 상황이에요. 이번에도 처음부터 시작해요.

모은 돈이 조금이라도 줄어드는 건 정말 싫어요. 그래도 세금을 아낄 수 있는 방법이 있다면 알아보고 싶어요. 그런 방법을 내가 쓸 수 있는지 확인해 보세요."

(끝나면) "방금 과제는 얼마나 쉬웠나요? 1부터 5까지 숫자로 말해 주세요."

> 기록용 성공 기준: 손실 불안 질문에서 '조금만 줄어도 잠이 안 와요'를 고르고, ISA 상세에서 조건 두 개에 답한 뒤 '다 했어요' → 로드맵으로 돌아옴 (결과 화면이 나오면 거기까지)

### 9) 사후 질문
"마지막으로 몇 가지만 여쭤볼게요."

1. "오늘 써 보면서 가장 헷갈렸던 곳은 어디였나요?"
2. "가장 좋았던 곳은 어디였나요?"
3. "이 서비스를 실제로 쓸 것 같나요? 그 이유는요?"
4. "로드맵을 다 본 뒤 나에게 맞는 상품 예시가 있었으면 좋겠나요? 있다면 어떤 정보가 보고 싶나요?"

(답이 짧으면) "조금만 더 말씀해 주실 수 있을까요?"

### 10) 감사 인사
"오늘 정말 감사해요. 말씀해 주신 내용은 서비스를 고치는 데만 쓸게요. 혹시 더 하고 싶은 말씀이 있으세요?"

## 5. 관찰할 것 (기록하는 사람용)

클로드 가상 UT에서 미리 찾은 문제가 실제로도 나오는지 특히 봐요. 나오면 기록지에 그 화면과 참가자가 한 말을 적어요.

| 볼 곳 | 볼 것 | 관련 문제 |
|---|---|---|
| 로드맵 0단계 | 금액을 적고 체크했을 때 금액이 사라지는 걸 알아채는지, 뭐라고 하는지 | F1 |
| 로드맵에 처음 왔을 때 | '지금 할 일'을 바로 찾는지, 무엇을 먼저 보는지 | 평가 목표 1 |
| 용어 미리 보기 | 용어를 펼쳐 보는지 건너뛰는지, 어떤 용어를 여는지 | 용어 |
| 적금·파킹통장 안내 | "그래서 어떤 상품을 고르라는 거지?", "은행 이름이 있으면 좋겠다" 같은 말 | F2, 평가 목표 3 |
| 적금 상세 | 제안 금액을 보고 "이 숫자 어디서 나왔지?" 같은 반응 / 파킹통장과의 차이를 찾는지 | F5, F6 |
| 용어 미리 보기의 적금 설명 (특히 P3) | "정해진 금액"을 보고 망설이는지 | F8 |
| ISA 상세 (특히 P2) | 원금 경고에서 멈추는지, 조건 2에서 답을 고민하는지 | F3, F4 |
| 단계 상세 화면 전체 | 끝까지 읽는지, 스크롤을 빨리 넘기는지, "길다", "그만할래요" 같은 말 | 평가 목표 2 |
| 결과 화면 | 매달 모을 금액 줄을 보고 이상하다고 하는지 | F7 |
