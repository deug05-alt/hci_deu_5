## 2. 플로우에서 기획서로

플로우에는 있지만 기획서의 기능이나 니즈에 적혀 있지 않은 것이에요.

| 플로우에 있는 것 | 나오는 곳 | 기획서 |
|---|---|---|
| 기기에 기록이 있으면 시작 화면을 건너뛰고 로드맵으로 바로 감 | 플로우 1~4, 1단계 갈림길 | 6.8은 저장과 안내만 있고 재방문 시 이동은 없음 |
| 진단의 '이전 질문', 4.1·4.2의 '뒤로 가기' | 플로우 1~4 진단 단계, 플로우 1 7~8단계 | 없음 |
| 2·3·4단계 카드를 눌러 단계 상세 화면(3.3, 3.4, 4.1)으로 들어감 | 플로우 1 6단계, 플로우 3 6·8단계, 플로우 4 6·8단계 | 6.3은 로드맵에서 체크하는 방식만 있고 단계 상세 화면은 없음 (4단계 진입은 6.1에 있음) |
| 3.4의 조건마다 '해당돼요 / 아니에요 / 잘 모르겠어요' 선택 | 3.4 | 6.3은 "내가 ISA를 써도 되는지 확인하기" 항목만 있음 |

## 3. 퍼소나로 다시 보기 (이길잡, 핵심 플로우 1)

퍼소나 카드와 인터뷰에 적힌 내용만 근거로 썼어요.

| 이길잡의 불편 (퍼소나 카드) | 관련 인터뷰 | 해결되는 지점 |
|---|---|---|
| 생소하고 어려운 금융 용어 | P4 복잡한 금융 용어, P8 기초 경제 지식, P9 상품·제도 이해 어려움 | 로드맵(3.0)과 3단계 상세(3.4)의 밑줄 용어 → 용어 사전(3.1). 단, 진단과 4단계 화면에는 용어 사전으로 가는 길이 없음 |
| 무엇부터 시작할지 몰라 결정 마비 | P2 단계별 로드맵, P6 어떤 것부터 해야 할지 모름, P8 시작부터 막막 | 한 화면 한 질문(2.1~2.3), 현재 단계만 펼친 로드맵(3.0), 4단계는 준비됐을 때 직접 누름 |
| 과거 손실 경험에 의한 원금 손실 공포 | P3 원금 손실 불안, P10 안전성 확인 불가, P5 하락 시 손실 최소화 장치 | 불안이 크면 4단계 숨김(3.0b), 손실 한도(4.1), 필수 안내(4.2), 한도 초과 차단(4.3), 하락 대응 규칙(4.4) |
| 대처 방식: 결정을 못 내린 채 파킹통장 예치금 상태로 방치 | P6·P7 지인에게 묻기 | 1단계 상세(3.2)의 은행 앱 화면 순서 안내. 단, 핵심 플로우 1에서는 3.2를 거치지 않음 |

**해결되지 않고 남은 불편**
- 이길잡의 목표 "나의 현재 소득 및 목적에 꼭 맞는 1:1 맞춤 추천 가이드": 진단은 여유자금·불안·수입 안정성만 묻고 **목적(무엇을 위해 모으는지)은 묻지 않아요.** 0단계의 "재테크 목표 적어 보기"는 기획 때 제외했어요. 또 서비스는 중립성 원칙 때문에 특정 상품을 추천하지 않아서, "추천"을 기대한 사용자에게는 기대와 다를 수 있어요.
- 이길잡의 대처 방식(방치)을 푸는 행동 지원(3.2)이 핵심 플로우에 없어요. (1의 '약함'과 같은 문제)

|---|---|---|---|---|
| 1 | 손실 한도 내리기 | 빠짐 | 4.3의 '한도 바꾸기'에서 올리기·내리기를 함께. 한도 설정(4.1)에서 슬라이더로 내리면 바로 적용, 올리면 재진단(4.5) | 새 화면 없이 기존 버튼과 화면으로 해결됨 |
| 2 | 단계별 화면 가이드(3.2)가 핵심 플로우에 없음 | 약함 | 핵심 플로우 1에 1단계 상세(3.2) 단계를 넣음 (플로우 1의 6~7단계) | 실제 행동 항목에서 3.2를 거쳐야 이길잡의 방치 습관을 푸는 핵심 가치가 드러남. 플로우 2~4와도 일관됨 |
| 3 | 기본 로드맵(3.0)의 '상황이 바뀌었어요' | 약함 | 플로우 1에 갈림길로 넣음 (3.0 → 2.1) | 기획서와 와이어프레임에 이미 있는 것을 플로우에 맞춤 |
| 4 | 0단계 항목을 적는 화면이 없음 | 약함 | 로드맵 안에서 항목을 펼쳐 바로 적음 (기존 화면에 합침) | 0단계는 가볍고 빠르게 끝나야 함 (기획서 6.3) |

| 6 | 단계 카드로 들어가는 상세 화면(3.3, 3.4)과 3.4의 조건 3택 | 기획서에 없음 | 기획서 6.3에 새로 넣음 | 이미 그린 화면(#s12, #s16)과 플로우를 기획서에 맞춤 |
| 7 | 진단의 '이전 질문', 4.1·4.2의 '뒤로 가기' | 기획서에 없음 | 기획서 6.1에 넣고 와이어프레임에 '뒤로' 표시 추가 (3, 4, 5, 8번) | 플로우·기획서·와이어프레임을 맞추고, 테스트 때 보여줄 화면이 있음 |
| 8 | 퍼소나의 목표 중 '목적에 맞는 가이드' | 퍼소나 점검에서 남은 불편 | 목적은 넣지 않음 | 팀 판단: 목적은 넣을 필요가 없음 |
