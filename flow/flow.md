# 서비스 플로우

## 플로우 1: 기본 흐름 (진단 → 로드맵 → 4단계) [핵심]
퍼소나: 이길잡 (보조 김안전) / 목표: 재테크를 어디서부터 시작할지 알고, 첫 행동을 정한다
| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | 시작 화면 (1.0) | '시작하기' 버튼 하나만 누른다 | 진단 1 여유자금 (2.1) | 기기에 기록이 있으면 버튼이 '이어서 하기'로 바뀌고, 누르면 저장된 로드맵 (3.0)으로 |
| 2 | 진단 1 여유자금 (2.1) | 매달 모을 수 있는 돈을 고르고 '다음'을 누른다 | 진단 2 손실 불안 (2.2) | |
| 3 | 진단 2 손실 불안 (2.2) | 줄어들 때의 느낌을 고르고 '다음'을 누른다 | 진단 3 수입 안정성 (2.3) | 이전 질문으로 돌아가기: 2.1 |
| 4 | 진단 3 수입 안정성 (2.3) | 수입 상태를 고르고 '다음'을 누른다 | 맞춤 로드맵 (3.0) | 이전 질문으로 돌아가기: 2.2 |
| 5 | 맞춤 로드맵 (3.0) | 현재 단계의 항목을 체크한다. 0단계 항목은 펼쳐서 바로 적는다(돈 흐름, 모을 금액). 모두 마치면 다음 단계가 열린다 | 맞춤 로드맵 (3.0) (다음 단계가 열린 상태) | 밑줄 친 용어를 누르면 용어 사전 (3.1), 닫으면 3.0으로 돌아옴. '이미 했어요'를 누르면 현재 단계 전체가 한 번에 체크되고 다음 단계가 열림 (4단계 제외). '상황이 바뀌었어요'를 누르면 진단 1 (2.1)부터 다시 |
| 6 | 맞춤 로드맵 (3.0) | 1단계의 '비상금 소액 옮겨 보기' 항목을 누른다 | 1단계 상세와 행동 지원 (3.2) | |
| 7 | 1단계 상세와 행동 지원 (3.2) | 은행 앱 화면 순서를 보고 소액을 옮긴 뒤 '다 했어요'를 누른다 | 맞춤 로드맵 (3.0) (그 항목이 체크됨) | |
| 8 | 맞춤 로드맵 (3.0) | 3단계까지 마쳐 열린 4단계 카드를 직접 누른다 | 손실 한도 설정 (4.1) | 자동으로 넘어가지 않음 |
| 9 | 손실 한도 설정 (4.1) | 화면 위의 이유 한 줄(앞에서는 느낌을 물었고 여기서는 실제 금액을 정한다는 설명)을 읽고, 추천값을 확인하고 슬라이더로 조정한 뒤 '다음'을 누른다 | 4단계 열기 전 필수 안내 (4.2) | 뒤로 가기: 로드맵 (3.0), 4단계 카드는 열린 채로 남음 |
| 10 | 4단계 열기 전 필수 안내 (4.2) | 네 문장을 읽고 확인 체크를 한 뒤 '4단계 시작하기'를 누른다 | 4단계 투자 금액 입력 (4.3) | 뒤로 가기: 로드맵 (3.0) |
| 11 | 4단계 투자 금액 입력 (4.3) | 투자 금액을 정한다 | 4단계 하락 대응 규칙 (4.4) | 한도를 넘는 금액: 입력을 막고 '내가 정한 한도예요'라고 안내, 4.3에 머무름. '한도 바꾸기'를 누르면 손실 한도 설정 (4.1)에서 슬라이더로 조정: 내리면 바로 적용되어 4.3으로 돌아오고, 올리면 한도 올리기 재진단 (4.5)을 거쳐 4.3으로 돌아옴 |
| 12 | 4단계 하락 대응 규칙 (4.4) | 규칙을 고르고 '내 규칙으로 저장'을 누른다 | 로드맵 완료 결과 (3.5) | |
| 13 | 로드맵 완료 결과 (3.5, 새 화면) | 해낸 것, 앞으로 필요한 것, 내가 정한 하락 대응 규칙을 보고 '내 로드맵 보기'를 누른다 | 맞춤 로드맵 (3.0), 4단계 완료 표시 | 끝 |

| 2 | 진단 1 여유자금 (2.1) | '5만 원 미만'을 고르고 '다음'을 누른다 | 진단 2 손실 불안 (2.2) | |
