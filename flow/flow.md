# 서비스 플로우

## 플로우 1: 기본 흐름 (진단 → 로드맵 → 4단계) [핵심]
퍼소나: 이길잡 (보조 김안전) / 목표: 재테크를 어디서부터 시작할지 알고, 첫 행동을 정한다
| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | 시작 화면 (1.0) | '시작하기' 버튼 하나만 누른다 | 진단 1 여유자금 (2.1) | 기기에 이전 기록이 있으면 시작 화면을 건너뛰고 맞춤 로드맵 (3.0)으로 이동 |
| 2 | 진단 1 여유자금 (2.1) | 매달 모을 수 있는 돈을 고르고 '다음'을 누른다 | 진단 2 손실 불안 (2.2) | |
| 3 | 진단 2 손실 불안 (2.2) | 줄어들 때의 느낌을 고르고 '다음'을 누른다 | 진단 3 수입 안정성 (2.3) | 이전 질문으로 돌아가기: 2.1 |
| 4 | 진단 3 수입 안정성 (2.3) | 수입 상태를 고르고 '다음'을 누른다 | 맞춤 로드맵 (3.0) | 이전 질문으로 돌아가기: 2.2 |
| 5 | 맞춤 로드맵 (3.0) | 현재 단계의 항목을 체크한다. 모두 마치면 다음 단계가 열린다 | 맞춤 로드맵 (3.0) (다음 단계가 열린 상태) | 밑줄 친 용어를 누르면 용어 사전 (3.1), 닫으면 3.0으로 돌아옴. '이미 했어요'를 누르면 현재 단계 전체가 한 번에 체크되고 다음 단계가 열림 (4단계 제외, 제안) |
| 6 | 맞춤 로드맵 (3.0) | 3단계까지 마쳐 열린 4단계 카드를 직접 누른다 | 손실 한도 설정 (4.1) | 자동으로 넘어가지 않음 |
| 7 | 손실 한도 설정 (4.1) | 화면 위의 이유 한 줄(앞에서는 느낌을 물었고 여기서는 실제 금액을 정한다는 설명)을 읽고, 추천값을 확인하고 슬라이더로 조정한 뒤 '다음'을 누른다 | 4단계 열기 전 필수 안내 (4.2) | 뒤로 가기: 로드맵 (3.0), 4단계 카드는 열린 채로 남음 |
| 8 | 4단계 열기 전 필수 안내 (4.2) | 네 문장을 읽고 확인 체크를 한 뒤 '4단계 시작하기'를 누른다 | 4단계 투자 금액 입력 (4.3) | 뒤로 가기: 로드맵 (3.0) |
| 9 | 4단계 투자 금액 입력 (4.3) | 투자 금액을 정한다 | 4단계 하락 대응 규칙 (4.4) | 한도를 넘는 금액: 입력을 막고 '내가 정한 한도예요'라고 안내, 4.3에 머무름 |
| 10 | 4단계 하락 대응 규칙 (4.4) | 규칙을 고르고 '내 규칙으로 저장'을 누른다 | 맞춤 로드맵 (3.0) | |
| 11 | 맞춤 로드맵 (3.0) | 4단계가 완료로 표시된 로드맵을 본다 | 끝 | |
