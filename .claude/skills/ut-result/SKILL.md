# 사용성 평가 결과 정리

## 시작하며 설명할 것

> 평가에서 찾은 문제를 한곳에 모으고, 무엇부터 고칠지 정해요. 모든 문제를 다 고칠 수는 없어서, 얼마나 심각한지와 고치기 쉬운지를 보고 팀이 순서를 정해요. 이 목록이 다음 주에 서비스를 완성할 때의 할 일 목록이 돼요.

## 준비

- `ut/plan.md`, `ut/claude-ut.md`, `ut/notes/` 안의 파일을 읽으세요. `ut/findings.md` 가 이미 있으면 읽고 이어서 고치세요.
- 사람 UT 기록이 없으면 클로드 UT 결과만으로 정리하고, "사람 UT 뒤에 다시 정리해요"라고 알려주세요.
- 사람 UT 기록 형식이 관찰 기록지와 다르면 그대로 읽되, 참가자가 한 말은 바꾸지 말고 옮기세요.

## 1. 문제 모으기

- 클로드 UT의 문제(C1, C2)와 사람 UT에서 나온 문제를 한 목록에 모으세요. 사람 UT 문제는 P1-1, P2-1, P3-1 처럼 참가자 번호를 붙이세요.
- 같은 문제는 하나로 합치고, 어디서 나왔는지 모두 적으세요 (예: C2, P1-3, P2-1).
- 팀이 "동의하지 않는다"고 한 클로드 문제는 목록에서 빼지 말고 "팀이 동의하지 않음"으로 표시하세요. 사람 UT에서 같은 문제가 나오면 다시 이야기할 거리예요.

## 2. 심각도 매기기

- 높음: 과제를 끝내지 못하게 막는다
- 중간: 헤매거나 도움을 받아야 끝낸다
- 낮음: 불편하지만 혼자 끝낸다

근거를 꼭 붙이세요. 사람 UT는 참가자가 한 말이나 행동 그대로, 클로드 UT는 claude-ut.md 의 어느 과제 어느 단계인지.

## 3. 클로드와 사람 비교 (사람 UT 기록이 있을 때)

| 구분 | 문제 번호 |
|---|---|
| 클로드도 찾고 사람에게서도 나온 것 | |
| 클로드만 찾은 것 | |
| 사람에게서만 나온 것 | |

사람에게서만 나온 문제가 있다면 클로드 가상 평가가 무엇을 놓치는지 팀과 한 줄로 이야기해 보세요. 보고서에 쓸 만한 내용이에요.

과제별 결과도 정리하세요: 과제마다 성공한 사람 수(3명 중 몇 명), 쉬움 점수 평균. 같은 문제가 몇 명에게서 나왔는지도 "나온 곳" 칸에 보이게 하세요. 3명 중 2명 이상이 같은 곳에서 막혔다면 우연이 아닐 가능성이 커요.

## 4. 개선안과 우선순위 (하나씩)

- 심각도가 높은 문제부터, 문제마다 개선안 후보를 2개씩 보여주세요. 한 줄로, 무엇을 어떻게 바꾸는지.
- 팀이 정하게 하세요: 이번에 고친다(5주차), 나중에, 고치지 않는다. 이유를 한 줄 받으세요.
- 이번에 고칠 것은 순서를 매기세요. 심각도가 높고 고치기 쉬운 것을 먼저 권하세요. 5주차 수업 한 번에 고칠 수 있는 양(5개 안팎)을 넘으면 알려주세요.
