# 강사님께 공유하기

결과물은 두 벌로 공유해요. HTML 파일은 GitHub 저장소에, 같은 화면을 아티팩트 링크로도 제출해요.

## 1. 파일 확인

- `flow/flow.html` 과 `design/prototype.html` 이 있는지 보세요. 없는 건 아직 안 만든 거라고 알려주세요.
- 두 파일이 다른 파일(css, js, 이미지)을 불러오고 있지 않은지 확인하세요. 불러오고 있으면 그 내용을 파일 안으로 옮기세요. flow.html 의 mermaid 주소(cdn.jsdelivr.net)는 그대로 둬도 돼요.
- 각 파일의 크기를 알려주세요. 아티팩트로 만들 때 채팅의 클로드가 파일을 통째로 다시 써야 해서, 클수록 사용량이 많이 들고 중간에 끊길 수 있어요. 100KB가 넘으면 줄일 방법(반복되는 스타일을 공통 스타일로 합치기, 안 쓰는 스타일 지우기)을 먼저 제안하세요.

## 2. GitHub에 올리기

- 저장하고 GitHub에 올리세요. 올린 뒤 두 파일의 GitHub 주소를 알려주세요.

## 3. 아티팩트로 만들기 안내

학생에게 아래 순서를 그대로 보여주세요.

1. 클로드 앱에서 **채팅** 탭으로 가서 새 채팅을 여세요.
2. `flow/flow.html` 파일을 채팅창에 끌어다 놓고 이렇게 보내세요: "첨부한 HTML을 한 글자도 바꾸지 말고 그대로 아티팩트로 보여줘"
3. 끝까지 다 만들어졌는지 확인하세요. 중간에 끊겼으면 "이어서 끝까지 써줘"라고 보내세요.
4. 아티팩트가 뜨면 오른쪽 위 공유 버튼에서 링크를 복사하세요. "링크가 있는 사람"이 볼 수 있게 되어 있는지 확인하세요.
5. `design/prototype.html` 도 새 채팅에서 같은 방법으로 하세요. 한 채팅에 둘 다 넣으면 사용량이 많이 들어요.
6. 가이드 페이지의 **제출하기** 칸에서 팀 이름과 두 링크를 제출하세요.
