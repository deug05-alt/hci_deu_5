# HCI 수업 3주차 스킬

동의대학교 인간컴퓨터상호작용(1) 수업에서 쓰는 클로드 코드 스킬이에요. 팀 프로젝트 폴더에 넣으면 `/flow` 처럼 `/` 로 불러 쓸 수 있어요.

## 설치

팀 폴더를 연 클로드 코드에 이 문장을 보내세요.

```
https://github.com/syuuyh522-stack/hci-claude-skills 저장소의 skills 폴더 안에 있는 스킬 폴더 7개를 이 폴더의 .claude/skills 안에 그대로 넣어줘. 저장소는 임시 폴더에 받고, 다 넣으면 임시 폴더는 지워줘. 같은 이름의 스킬이 있으면 덮어써. 끝나면 넣은 스킬 이름만 알려줘
```

그다음 **같은 폴더로 새 세션**을 열면 `/` 목록에 스킬이 보여요.

직접 받으려면 이 페이지의 **Code** 버튼에서 **Download ZIP** 을 누르고, 압축을 푼 뒤 `skills` 안의 폴더 7개를 팀 폴더의 `.claude/skills` 안에 넣으세요.

## 스킬 순서

| 순서 | 스킬 | 하는 일 | 결과 파일 |
|---|---|---|---|
| 1 | `/project-map` | 흩어진 기획서, 퍼소나, 메뉴 구조, 와이어프레임을 찾아 한 장으로 정리하고 화면 ID를 붙여요 | docs/project-map.md |
| 2 | `/flow` | 시나리오마다 화면, 행동, 갈림길을 이어 플로우를 그리고, 전체 플로우로 합쳐 점검해요 | flow/flow.md, flow/flow.html |
| 3 | `/add-screen` | 필요하다고 정했지만 와이어프레임이 없는 화면을 하나씩 그려요 | 기존 와이어프레임 폴더 |
| 4 | `/plan-check` | 플로우를 기준으로 기획서의 핵심 기능을 다시 점검해요 | flow/plan-check.md |
| 5 | `/design` | 디자인 방향을 정하고, 핵심 플로우 화면부터 눌러보는 화면을 하나씩 만들어요. `/design 점검` 으로 전체 점검 | design/style-guide.md, screens.md, prototype.html |
| 6 | `/report` | 오늘 한 일을 보고서에 넣을 한 장 요약판으로 만들고 이미지로 저장해요 | report/summary.html, summary.png |
| 7 | `/share` | 결과물을 GitHub에 올리고 아티팩트 링크로 제출하는 방법을 안내해요 | |

스킬은 우리 팀 자료를 근거로 질문하고, 디자인 판단은 팀이 내리게 되어 있어요.
