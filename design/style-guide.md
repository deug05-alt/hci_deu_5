# 차근차근 스타일 가이드

## 느낌 세 단어
**차분하다, 믿음직하다, 친절하다**
- 이유: 주 타겟 이길잡은 용어가 어렵고 결정을 못 내리며 원금 손실을 두려워해요(P3, P10). 들뜬 느낌보다 안정감을 주고, 슬로건 "막막할 땐, 차근차근"처럼 천천히 안내하는 분위기로 가요.

## 색
| 이름 | 색상 코드 | 쓰는 곳 |
|---|---|---|
| 주 색 (남색) | `#2B4C7E` | 주 버튼 배경, 선택된 선택지, 진행 바, 현재 단계 카드 테두리, 밑줄 용어 |
| 주 색 옅게 | `#E8EDF5` | 선택된 항목의 배경, 정보 안내 상자 |
| 강조 색 (노랑) | `#F2B705` | "진행 중" 표시, 주의 안내 상자의 왼쪽 띠, 체크 완료 표시 배경. **흰 배경 위 글자색으로는 쓰지 않아요** (대비가 낮아 읽기 어려움) |
| 강조 색 옅게 | `#FFF6D9` | 주의 안내 상자 배경 |
| 글자 | `#1D1D1F` | 본문, 제목 |
| 보조 글자 | `#55555C` | 설명, 보조 안내. 흰 배경에서 충분히 읽히는 진하기 (더 연한 회색은 쓰지 않아요) |
| 선 | `#D5DAE2` | 카드·입력칸 테두리, 구분선 |
| 배경 | `#FFFFFF` | 화면 배경 |
| 바탕 회색 | `#F3F5F9` | 잠긴 단계 카드, 하단 안내 띠 |

주 색 버튼의 글자는 흰색(`#FFFFFF`)이에요. 노랑 위에 글자를 쓸 때는 글자색(`#1D1D1F`)을 써요.

## 글자
기본 글꼴(아이폰 Apple SD 산돌고딕 Neo, 윈도우 맑은 고딕)을 쓰고 굵기와 크기로 단정하고 또렷하게 표현해요.

| 단계 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| 제목 | 22px | 굵게(700) | 화면 제목, 질문 |
| 소제목 | 17px | 굵게(700) | 카드 제목, 단계 이름 |
| 본문 | 15px | 보통(400), 줄 간격 1.6 | 설명, 선택지 |
| 보조 | 13px | 보통(400) | 진행 표시, 안내, 하단 문구 |
| 버튼 글자 | 16px | 굵게(700) | 주 버튼, 보조 버튼 |
| 작은 버튼 | 14px | 보통(400) | 글자 버튼(이미 했어요, 한도 바꾸기), 조건 칩, 화면 순서 보기 |
| 큰 숫자 | 30px (입력칸은 22px) | 굵게(700) | 손실 한도 금액, 투자 금액 입력칸 |

가장 작은 글자는 13px이에요. 12px는 쓰지 않아요. (`/design 점검`에서 정리)

## 모양
- 모서리 둥글기: 12px (카드, 버튼, 입력칸 모두 같게)
- 버튼
  - 주 버튼: 주 색 배경, 흰 글자, 높이 52px, 화면 폭 가득. 화면마다 하나만
  - 보조 버튼: 흰 배경, 주 색 테두리와 글자, 높이 48px
  - 글자 버튼: 밑줄 글자 (예: 이미 했어요, 한도 바꾸기), 누르는 영역 높이 44px 이상
  - 누를 수 없는 상태: 바탕 회색 배경, 보조 글자색
- 누르면 반응: 눌릴 때 살짝 어두워지고, 선택지는 선택되면 주 색 테두리와 옅은 주 색 배경

## 기본 부품 (우리 서비스에서 쓰는 것)
| 부품 | 쓰는 화면 |
|---|---|
| 상단 바 (뒤로, 진행 표시) | 진단, 4단계, 단계 상세 |
| 진행 바 | 진단 2.1~2.3 |
| 선택지 버튼 (하나 고르기) | 진단, 하락 대응 규칙, 3단계 조건 |
| 주 버튼 / 보조 버튼 / 글자 버튼 | 모든 화면 |
| 단계 카드 (진행 중, 잠김, 완료) | 로드맵 |
| 체크 항목 | 로드맵, 단계 상세 |
| 안내 상자 (정보 / 주의) | 시작, 한도, 4단계 안내, 단계 상세 |
| 입력칸, 슬라이더 | 0단계 금액, 손실 한도, 투자 금액 |
| 바텀시트 | 용어 사전 |
| 하단 안내 띠 | 모든 화면 ("투자 권유가 아니라 정보·교육을 위한 서비스예요") |

하단 메뉴는 쓰지 않아요. 와이어프레임과 같이 한 화면에 하나의 흐름만 보여 줘요.

## 버튼 이름 규칙
- 로드맵으로 돌아가는 뒤로 버튼: "← 로드맵"
- 바로 앞 화면으로 가는 버튼: "← 뒤로" (진단에서는 "← 이전 질문")
- 단계 상세를 마칠 때: "다 했어요"
