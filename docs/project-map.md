## 핵심 기능 (기획서 그대로)
기획서 7절 MVP 범위의 "포함" 항목입니다.
1. 진단 질문 3개 + 맞춤 로드맵(5단계 체크리스트)
2. 손실 한도 설정·변경
3. 4단계 필수 안내 화면
4. 쉬운 용어 사전
5. 단계별 화면 가이드

## 주요 사용 시나리오 (기획서 그대로)
기획서에 "주요 사용 시나리오"라는 이름의 절은 없습니다. 아래 둘이 가장 가깝습니다.

사용자 흐름 (6.1):
1. 접속 (회원가입 없음)
2. 한 화면에 한 질문씩 진단 3문항
3. 맞춤 로드맵(체크리스트) 확인. 현재 단계만 펼침
4. 체크리스트 진행 중 어려운 용어는 눌러서 용어 사전으로 확인
5. 4단계(소액 주식 준비하기)를 처음 열 때: 손실 한도 설정, 필수 안내 화면 확인, 4단계 체크리스트

사용자 테스트 시나리오 (11절):
- A. 여유자금이 적은 경우: 매달 모을 수 있는 돈이 5만 원도 안 되는 사람
- B. 수입이 달라지는 경우: 월급이 아니라 달마다 수입이 달라지는 사람
- C. 손실 불안이 큰 경우: 투자한 돈이 조금만 줄어도 잠이 안 오는 사람
