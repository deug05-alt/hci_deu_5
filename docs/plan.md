## 2. 문제 정의
인터뷰 10명의 공통 문제는 **"시작을 못 함"**입니다. 세 가지 원인이 겹칩니다.

| 원인 | 근거 응답자 | 대표 내용 |
|---|---|---|
| 여윳돈(시드머니) 부족 | P1, P2, P6, P8, P10 | 가장 먼저 해결할 문제로 "여윳돈 마련"을 꼽음 |
| 용어·정보의 어려움 | P2, P4, P5, P6, P8, P9, P10 | 어디서부터 해야 할지 모르고, 정보가 많아 고르기 어려움 |
| 원금 손실 불안 | P3, P4, P5, P10 | 안전성 확인 불가, 하락 시 대응 방안 부족 |

기존 대처 방식은 지인에게 묻기(P6, P7), 포털 검색(P10), 유튜브·SNS 탐색(P1, P2, P4)이었고, 결국 실행하지 못하고 미루는 경우가 많았습니다.

## 3. 타겟
| 구분 | 페르소나 | 특징 | 근거 응답자 |
|---|---|---|---|
| 주 타겟 | Type B 이길잡 (26세 사회초년생) | 가이드가 필요하고 결정 마비를 겪음 | P2, P5, P6, P8 |
| 보조 타겟 | Type A 김안전 (23세 대학생) | 안전 지향, 직접 비교하는 성향 | P4, P7, P9, P10 |

주 타겟을 위한 온보딩 가이드가 중심이고, 보조 타겟의 안전 지향 성향은 손실 한도 장치와 안전 안내에 반영합니다. 보조 타겟이 원하는 상품 비교 기능은 후속 버전 후보입니다.

**보조 타겟 대응 (확정)**: MVP에서는 안전 안내(손실 한도, 원금 보장 상품 안내)만 유지하고, 상품 비교는 후속 버전으로 둡니다. 김안전은 서비스의 주 사용자가 아니라는 점을 받아들이며, 이 유형이 이탈할 가능성이 있다는 점은 사용자 테스트에서 확인합니다.

## 4. 핵심 컨셉과 차별점
**맞춤 온보딩 가이드.** 여유자금, 손실 불안 정도, 수입 안정성을 묻고, 쉬운 용어로 단계별 시작 로드맵을 제안합니다.

**차별점: 가입 전 "무엇부터 할지"를 정해 주는 시작 전 단계에 집중합니다.**
- 기존 금융 앱은 상품 조회와 가입이 중심입니다. 응답자 중에도 주식 앱을 조회·확인 위주로 쓰는 경우가 있었습니다(P4 토스 증권 조회, P6 토스 주식 확인, P10 나무증권 앱 확인만 해봄).
- 보조 차별점: 중립성(상품 판매 없음), 손실 한도 기반 안전장치

## 5. 경쟁·대체 수단 비교
인터뷰에서 응답자가 실제로 쓴 수단을 기준으로 정리했습니다. 각 서비스의 최신 기능은 확인하지 않았으므로, 아래 내용은 인터뷰 응답에서 확인되는 사용 방식에 한정합니다.

| 구분 | 응답자 사용 사례 | 응답자가 겪은 한계 | 차근차근의 차이 |
|---|---|---|---|
| 금융 앱 (토스, 카카오뱅크, 나무증권) | P1 토스 굴비·적금, P3·P4·P6 토스 증권·주식 확인, P6 카카오뱅크 저금통, P10 나무증권 앱 확인 | 조회·확인에서 멈추는 경우(P4, P6, P10), 복잡한 금융 용어(P4) | 가입 전에 "무엇부터 할지"를 순서로 정해 줌, 상품 판매 없이 중립 |
| 유튜브·SNS 재테크 콘텐츠 | P1 유튜브·인스타 스레드, P2 인스타·유튜브, P4 유튜브, P5 트위터 | 정보가 방대해 선별이 어려움(P5), 불확실한 정보(P1) | 내 여유자금·손실 불안·수입 안정성에 맞춘 개인화된 순서 |

미확인: 각 금융 앱이 현재 제공하는 초보자 안내 기능의 범위. 실제 경쟁 분석 단계에서 직접 사용해 확인합니다.

## 6. 서비스 구성

### 6.1 사용자 흐름
1. 접속 (회원가입 없음)
2. 한 화면에 한 질문씩 진단 3문항
3. 손실 한도 설정
4. 맞춤 로드맵(체크리스트) 확인. 현재 단계만 펼침
5. 체크리스트 진행 중 어려운 용어는 눌러서 용어 사전으로 확인

회원가입 없이 바로 시작해 진입 장벽을 낮추고, 한 화면 한 질문으로 결정 마비를 줄입니다.

### 6.2 진단 질문 (3개 축, 선택지 확정)
| 질문 축 | 질문 | 선택지 | 근거 |
|---|---|---|---|
| 여유자금 규모 | 매달 모을 수 있는 돈은 어느 정도예요? (정확하지 않아도 된다고 안내) | 5만 원 미만 / 5~20만 원 / 20~50만 원 / 50만 원 이상 | P1, P2, P6, P8, P10 |
| 손실 불안 정도 | 투자한 돈이 줄어들면 어떨 것 같아요? (정답이 없다고 안내) | 조금만 줄어도 잠이 안 와요 / 조금은 괜찮지만 많이 줄면 힘들어요 / 어느 정도 줄어드는 건 감수할 수 있어요 | P3, P4, P10 |
| 수입 안정성 | 매달 들어오는 수입은 어떤가요? | 월급처럼 매달 비슷해요 / 달마다 차이가 있어요 / 아직 정해진 수입이 없어요 | P7, 김안전 페르소나 |

- 소액 구간을 따로 두어 여윳돈이 적은 사용자도 시작할 수 있게 합니다.
- 세 축의 답으로 로드맵에서 보여 줄 단계와 제안 금액을 정합니다. (6.2-1 참고)
- 금융 지식 수준은 묻지 않고 용어 사전으로 보완합니다.

### 6.2-1 진단 답에 따른 로드맵 규칙 (확정)
| 진단 답 | 로드맵 처리 | 근거 |
|---|---|---|
| 손실 불안: 조금만 줄어도 잠이 안 와요 | 4단계(소액 주식)를 숨기고 3단계(ISA)까지만 보여 줌. 진단을 다시 하면 열림 | P3, P10 |
| 여유자금: 5만 원 미만 | 0~2단계만 보여 주고, 나머지는 "여유가 생기면 다시 진단해 보세요"라고 안내 | P1, P2, P6, P8, P10 |
| 수입: 달마다 차이가 있어요 / 아직 정해진 수입이 없어요 | 2단계(적금) 앞에 유연한 상품(자유적금 등) 안내를 추가하고, "납입이 부담되면 중도 해지할 수 있어요"를 알리며 납입 금액을 더 낮게 제안 | P7, P1(자유 적금 경험) |

- 규칙이 겹치면 더 보수적인 쪽을 따릅니다. 예: 여유자금 5만 원 미만이고 잠이 안 온다면 0~2단계만 보여 줍니다.
- 숨긴 단계는 "숨겼다"는 사실을 알립니다. 로드맵 하단에 "나머지 단계는 상황이 바뀌면 열어 드릴게요"와 "상황이 바뀌었어요" 버튼을 둡니다.
- 위 세 줄에 해당하지 않는 답(예: 여유자금 5만 원 이상, 월급형 수입, 감수 가능)은 5단계를 모두 보여 줍니다.
- 숨긴 단계 다시 열기 (확정): 로드맵 하단 버튼 "상황이 바뀌었어요"로 진단 3문항을 다시 하면 로드맵이 새로 계산됩니다. 기존의 "진단 다시 하기"는 이 버튼으로 통합합니다.
- 유연한 상품 안내의 구체 내용과 문구는 미정입니다. (와이어프레임 12번 화면의 문구는 임시)

### 6.3 로드맵: 5단계 체크리스트 (확정)
진단 결과에 맞는 해야 할 일을 단계별로 묶어 보여 주고, 사용자가 스스로 체크하며 진행합니다. 항목이 많으면 결정 마비가 생길 수 있어서 **현재 단계의 항목만 펼치고 나머지는 접어 둡니다.** 안전 상품에서 주식까지 단계적으로 넓히되, 원금 손실 불안이 큰 사용자(P3, P4, P10)는 안전 상품부터 시작하고, 주식·코인 관심(P2, P3, P8, P9)은 뒤 단계에서 받아 줍니다.

| 단계 | 체크리스트 항목 | 근거 |
|---|---|---|
| 0. 용어·기초 익히기 | 내 한 달 돈 흐름 적어 보기 / 매달 모을 금액 정하기 | P6, P8 / P1, P2, P6, P8, P10 |
| 1. 파킹통장 (원금 보장) | 파킹통장이 뭔지 알아보기 / 비상금 소액 옮겨 보기 | P4, P8 / P1, P2, P8 |
| 2. 적금 (원금 보장) | 적금이 뭔지, 파킹통장과 뭐가 다른지 알아보기 / 내가 부담 없이 납입할 금액 정하기 | P2, P3 / P7 |
| 3. ISA | ISA가 뭔지, 왜 절세가 되는지 알아보기 / 내가 ISA를 써도 되는지 확인하기 | P9 |
| 4. 소액 주식 | 내 손실 한도 안에서 투자 금액 정하기 / 하락했을 때 어떻게 할지 미리 정하기 | P5, P3 |

항목 선정에서 제외한 후보:
- 0단계: 금융 용어 3개 알아보기(용어 사전이 대신함), 재테크 목표 적어 보기
- 1단계: 이자율·조건 비교, 안전한지 확인하기(예금자 보호)
- 2단계: 이자율·우대조건 비교, 자동이체 설정
- 3단계: 적금과 ISA 차이 비교, ISA 유형 고르기(상품 선택에 가까워 중립성과 충돌 우려)
- 4단계: 가상 연습(MVP 범위 초과)
- 제외한 후보는 후속 버전에서 다시 검토합니다.

### 6.4 손실 한도 (안전장치)
사용자가 "내가 감당할 수 있는 최대 손실 금액"을 정하고, 4단계(소액 주식)는 그 한도 안에서만 진행됩니다. 근거: P3, P4, P5 (원금 손실 불안, 하락 시 손실 최소화 장치 요구)

| 상황 | 동작 (확정) |
|---|---|
| 입력 | 여유자금 구간과 불안 정도로 추천 금액을 미리 잡아 주고, 슬라이더로 직접 조정 |
| 한도 초과 입력 | 입력할 수 없게 막고 "내가 정한 한도예요"라고 이유를 안내 |
| 한도 내리기 | 바로 변경 |
| 한도 올리기 | 손실 불안 질문(진단 2번) 1개를 다시 묻고, 올리려는 한도의 위험을 안내하는 화면에서 확인하면 변경. 나머지 진단 문항은 다시 묻지 않음 |

한계: 기기에만 저장하는 구조라 사용자가 기록을 지우고 다시 시작하면 한도를 우회할 수 있습니다. 한도는 강제 차단이 아니라 사용자 스스로 정한 안전장치라는 점을 전제로 합니다.

### 6.5 4단계 열기 전 필수 안내 화면
"주식은 원금이 줄 수 있다"는 내용을 체크리스트 항목이 아니라, 단계가 열리기 전에 읽고 체크박스로 확인해야 넘어가는 화면으로 둡니다. 설계 원칙 "손실 위험은 숨기지 않고 먼저 알린다"를 지키는 장치입니다.

1. 주식은 원금이 줄 수 있어요. 투자한 돈의 일부 또는 전부를 잃을 수도 있어요.
2. 내 손실 한도는 (설정 금액)이에요. 이 금액 안에서만 시작해요.
3. 차근차근은 특정 종목이나 상품을 추천하지 않아요.
4. 투자 결정의 책임은 본인에게 있어요.

문구의 법적 적절성은 10절 검토 항목으로 남아 있습니다.

### 6.6 행동 지원: 단계별 화면 가이드 + 안전 안내
"비상금 소액 옮겨 보기"처럼 실제 행동이 필요한 항목은 결정을 못 내리고 방치하기 쉬우므로 다음과 같이 돕습니다.
- 은행 앱에서 누를 화면 순서를 그림과 글로 설명합니다.
- "소액이라 부담 없고, 언제든 다시 꺼낼 수 있다"는 안전 안내를 함께 보여 줍니다.
- 특정 은행 앱으로 연결하거나 상품을 추천하지 않습니다. (중립성 유지)
- 안내 수준 (확정): 은행 공통의 일반 순서 3단계 + 화면 그림 자리. 특정 은행을 정하지 않습니다. 1단계 예시: ① 쓰고 있는 은행 앱을 열어요 ② 이자를 주는 입출금 통장(파킹통장)을 골라요 ③ 부담 없는 금액을 옮겨 보세요
- 한계: 은행마다 실제 화면이 달라 안내와 정확히 맞지 않을 수 있습니다. 테스트에서 확인합니다.

### 6.7 쉬운 용어 사전
본문 안의 어려운 금융 용어를 누르면 바텀시트로 쉬운 말, 예시, 주의점을 보여 줍니다. 근거: P4(복잡한 금융 용어), P5, P8(기초 경제 지식), P9

### 6.8 진행 상황 저장: 기기에만 저장
- 진단 답, 손실 한도, 체크 상태를 사용자의 브라우저에 저장하고 서버로 보내지 않습니다. 개인정보를 받지 않아 부담이 작고 MVP 범위에 맞습니다.
- 한계: 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다. 이 점을 사용자에게 미리 안내합니다.
- 안내 시점 (확정): 시작 화면과 로드맵 화면 하단, 두 곳에서 한 번씩 알립니다.
  - 시작 화면: "기록은 이 기기에만 저장돼요. 기기를 바꾸거나 브라우저 데이터를 지우면 사라져요."
  - 로드맵 하단: "진행 상황은 이 기기에만 저장돼요."
- 선택적 가입(여러 기기에서 이어쓰기)은 후속 버전 후보입니다.

## 7. MVP 범위
| 포함 | 후속 후보 |
|---|---|
| 진단 질문 3개 + 맞춤 로드맵(5단계 체크리스트) | 상품 비교표 |
| 손실 한도 설정·변경 | 소액 시드머니 플래너 |
| 4단계 필수 안내 화면 | 모의투자·연습 공간 |
| 쉬운 용어 사전 | 선택적 가입(기기 간 이어쓰기) |
| 단계별 화면 가이드 | 리마인드 알림 |

## 8. 설계 원칙
- 쉬운 말을 쓴다. 전문 용어는 풀어서 쓴다.
- 한 화면에 하나의 결정만 요청한다 (결정 마비 방지).
- 손실 위험은 숨기지 않고 먼저, 쉬운 말로 알려 준다.
- 특정 상품을 사라고 권유하지 않고 정보와 학습을 제공한다.

## 9. 성공 지표
- **진단 완료율 (확정)**: 시작 화면에서 진단 3문항을 끝까지 답한 사용자 비율. 한 화면 한 질문 구조가 결정 마비를 줄였는지 확인합니다.
- 한계: 진단 완료는 "시작"까지만 보여 주고 실제 행동(체크 완료)은 보여 주지 않습니다. 1단계 체크 완료율, 재방문율은 후속 지표 후보입니다.

## 10. 법적·규제 검토
**방향 (확정)**: 서비스가 투자 권유가 아니라 **정보·교육 제공**임을 화면에 밝히고, 기획서에는 확인할 항목만 기록합니다. 실제 법률 자문은 실서비스 단계에서 받습니다. 아래는 결론이 아니라 확인해야 할 질문 목록입니다.

1. 손실 한도와 단계별 로드맵이 투자 자문·권유로 해석될 수 있는지
2. 화면에 넣을 정보·교육 목적 안내 문구와 위치
3. 4단계 필수 안내 화면의 문구가 충분한지
4. 상품 종류를 설명하는 것과 특정 상품 추천의 경계
5. 기기 저장 방식에서 개인정보를 수집하지 않는다는 점의 확인 (이후 가입 기능을 넣을 경우 재검토)

## 11. 사용자 테스트 계획
**방식 (확정)**: 저충실도 와이어프레임 사용성 테스트, 5~6명. 와이어프레임을 보여 주고 과제를 수행하게 하며, 생각을 말하면서 사용하도록 관찰합니다.

**대상**: 인터뷰 참여자(P1~P10) 중 일부와, 재테크를 시작하지 못한 비슷한 20대. 이길잡 유형(가이드 필요)과 김안전 유형(안전·비교 지향)을 섞어 모집합니다. 인터뷰 참여자는 서비스 취지를 이미 알아 편향이 있을 수 있으므로, 처음 보는 사람을 최소 2명 포함합니다. (제안)

**검증 항목 (확정)**
| 검증 항목 | 보는 것 | 관련 기획 |
|---|---|---|
| 손실 한도 설정이 이해되고 안심이 되는지 | 한도 개념을 이해하는지, 추천값에 수긍하는지, 안심인지 부담인지, 한도 초과 차단을 어떻게 받아들이는지 | 6.4, 6.5 |
| 로드맵으로 "무엇부터 할지" 알게 되는지 | 테스트 후 "다음에 무엇을 하겠느냐"는 질문에 구체적으로 답하는지, 체크리스트 흐름이 이해되는지 | 6.3, 4절 차별점 |

검증 항목으로 고르지 않은 것(진단 문항의 이해도, 용어 사전, 숨긴 단계의 자연스러움)은 이번 테스트에서 따로 묻지 않고, 관찰 중 문제가 보이면 기록합니다. 보조 타겟(김안전 유형)이 "비교 기능이 없어서 아쉽다"고 말하는지도 함께 기록합니다.

**과제 초안 (제안, 확정 전)**
1. 시작 화면에서 서비스가 무엇을 해 주는지 설명해 보세요.
2. 진단 3문항에 답하고 손실 한도를 정해 보세요. 이 한도가 의미하는 바를 설명해 보세요.
3. 로드맵에서 지금 해야 할 일을 찾아 말해 보세요.
4. (4단계 열림 상태에서) 한도보다 큰 금액을 입력해 보세요. 어떻게 느꼈는지 말해 주세요.
5. 테스트가 끝난 뒤: 오늘 이후 가장 먼저 무엇을 하겠습니까?

**성공 기준**: 숫자 기준은 아직 정하지 않았습니다. 정성적으로는 5~6명 중 대부분이 5번 질문에 구체적인 행동으로 답하는지를 봅니다.
