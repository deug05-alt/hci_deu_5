# 서비스 기획서 (초안)

> 상태: 초안. 질문과 답변으로 하나씩 구체화하는 중입니다. `(미정)` 표시는 아직 결정하지 않은 항목입니다.

## 1. 서비스 개요
- **서비스명**: 차근차근
- **한 줄 정의**: 재테크를 시작하지 못하는 20대 사회초년생에게 쉬운 말로 단계별 시작 로드맵을 알려주는 맞춤 온보딩 가이드
- **형태**: 모바일 웹

## 2. 문제 정의 (인터뷰 P1~P10 근거)
공통 문제는 "시작을 못 함"입니다. 세 가지 원인이 겹칩니다.

| 원인 | 근거 응답자 | 대표 내용 |
|---|---|---|
| 여윳돈(시드머니) 부족 | P1, P2, P6, P8, P10 | 가장 먼저 해결할 문제로 "여윳돈 마련"을 꼽음 |
| 용어·정보의 어려움 | P2, P4, P5, P6, P8, P9, P10 | 어디서부터 해야 할지 모르고, 정보가 많아 고르기 어려움 |
| 원금 손실 불안 | P3, P4, P5, P10 | 안전성 확인 불가, 하락 시 대응 방안 부족 |

기존 대처 방식은 지인에게 묻기(P6, P7), 포털 검색(P10), 유튜브·SNS 탐색(P1, P2, P4)이었고, 결국 실행하지 못하고 미루는 경우가 많았습니다.

## 3. 타겟
- **주 타겟**: Type B 이길잡 (26세 사회초년생, 가이드 필요, 결정 마비)
  - 근거 응답자: P2, P5, P6, P8
- **보조 타겟**: Type A 김안전 (23세 대학생, 안전 지향, 직접 비교)
  - 근거 응답자: P4, P7, P9, P10
  - 로드맵 안의 상품 비교 단계에서 참고합니다.

## 4. 핵심 컨셉
**맞춤 온보딩 가이드.** 여유자금, 손실 불안 정도, 수입 안정성을 묻고, 쉬운 용어로 단계별 시작 로드맵을 제안합니다.

## 5. MVP 기능
| 기능 | 설명 | 근거 |
|---|---|---|
| 진단 질문 + 맞춤 로드맵 | 여유자금, 손실 불안, 수입 안정성을 묻고 나에게 맞는 단계별 시작 로드맵을 만든다 | P2(단계별 로드맵 가이드), P6, P8, P9 |
| 쉬운 용어 사전 | 본문 안의 어려운 금융 용어를 누르면 쉬운 말로 풀어 준다 | P4(복잡한 금융 용어), P5, P8(기초 경제 지식), P9 |

### 진단 질문 (확정 3개 축)
| 질문 축 | 묻는 내용 | 근거 |
|---|---|---|
| 여유자금 규모 | 매달 모을 수 있는 금액 | P1, P2, P6, P8, P10 (가장 먼저 해결할 문제가 여윳돈 마련) |
| 손실 불안 정도 | 원금 손실을 얼마나 두려워하는지 | P3, P4, P10 |
| 수입 안정성 | 정기 수입이 있는지, 불규칙한지 | P7 (적금 만기 유지 걱정), 김안전 페르소나 |

### 진단 선택지 (확정)
**1. 여유자금 규모**: 매달 모을 수 있는 돈 (정확하지 않아도 된다고 안내)
- 5만 원 미만 / 5~20만 원 / 20~50만 원 / 50만 원 이상
- 소액 구간을 따로 두어 여윳돈이 적은 사용자도 시작할 수 있게 합니다.

**2. 손실 불안 정도**: "투자한 돈이 줄어들면 어떨 것 같아요?" (상황 선택형 3단계)
- 조금만 줄어도 잠이 안 와요 / 조금은 괜찮지만 많이 줄면 힘들어요 / 어느 정도 줄어드는 건 감수할 수 있어요
- 정답이 없는 질문이라고 함께 안내합니다.

**3. 수입 안정성**
- 월급처럼 매달 비슷해요 / 달마다 차이가 있어요 / 아직 정해진 수입이 없어요

세 축의 답으로 로드맵의 시작 단계와 속도를 정합니다. 금융 지식 수준은 질문하지 않고, 용어 사전으로 보완합니다.

### 로드맵 형태: 체크리스트
- 진단 결과에 맞는 해야 할 일을 목록으로 한 번에 보여 주고, 사용자가 스스로 체크하며 진행합니다.
- 5단계(0단계 용어·기초 익히기, 1단계 파킹통장, 2단계 적금, 3단계 ISA, 4단계 소액 주식)별로 묶어 전체 흐름을 볼 수 있게 합니다.
- 주의: 항목이 많으면 결정 마비가 생길 수 있어서, 현재 단계의 항목만 펼치고 나머지는 접어 둡니다. (설계 원칙 "한 화면에 하나의 결정"과 충돌하지 않게 하는 장치)

### 손실 불안 완화 장치: 손실 한도 설정
- 사용자가 "내가 감당할 수 있는 최대 손실 금액"을 정합니다.
- 체크리스트는 그 한도 안에서만 다음 단계(특히 소액 주식)를 열어 줍니다.
- 근거: P3, P4, P5 (원금 손실 불안, 하락 시 손실 최소화 장치 요구)
- 입력 방식(확정): 여유자금 구간과 불안 정도로 추천 금액을 미리 잡아 주고, 슬라이더로 직접 조정합니다.
- 한도 초과 시 (확정): 한도를 넘는 금액은 입력할 수 없게 막고, "내가 정한 한도예요"라고 이유를 안내합니다.
- 한도를 바꾸는 방법(한도 재설정 화면, 변경 시 확인 절차)은 미정입니다.

### 0단계 체크리스트 (확정): 용어·기초 익히기
| 항목 | 내용 | 근거 |
|---|---|---|
| 내 한 달 돈 흐름 적어 보기 | 들어오는 돈과 나가는 돈을 대략 적어 봄 | P6 (잔고 확인 후 필요성 인지), P8 (여윳돈 부족) |
| 매달 모을 금액 정하기 | 진단의 여유자금 구간을 바탕으로 구체적인 금액을 정함 | P1, P2, P6, P8, P10 (여윳돈 마련이 시작점) |

제외한 후보: 금융 용어 3개 알아보기(용어 사전 기능이 대신함), 재테크 목표 적어 보기.

### 1단계 체크리스트 (확정): 파킹통장 만들기
| 항목 | 내용 | 근거 |
|---|---|---|
| 파킹통장이 뭔지 알아보기 | 이자를 주는 입출금 통장이라는 개념을 쉬운 말로 설명 (용어 사전 연결) | P4, P8 (용어 어려움) |
| 비상금 소액 옮겨 보기 | 부담 없는 작은 금액으로 실제 행동을 시작 | P1, P2, P8 (여윳돈 부족) |

제외한 후보: 이자율·조건 비교해 보기, 안전한지 확인하기(예금자 보호). 2단계 이후나 후속 버전에서 다시 검토합니다.

### 2단계 체크리스트 (확정): 적금 시작하기
| 항목 | 내용 | 근거 |
|---|---|---|
| 적금이 뭔지, 파킹통장과 뭐가 다른지 알아보기 | 만기와 중도 해지 개념을 포함해 쉽게 설명 | P2 (적금 미루다 기간 종료), P3 (적금 중도 해지) |
| 내가 부담 없이 납입할 금액 정하기 | 진단의 여유자금과 수입 안정성 답을 바탕으로 적정 금액 제안 | P7 (만기 유지 걱정) |

제외한 후보: 이자율·우대조건 비교, 자동이체 설정. 후속 버전에서 다시 검토합니다.

### 3단계 체크리스트 (확정): ISA 알아보기
| 항목 | 내용 | 근거 |
|---|---|---|
| ISA가 뭔지, 왜 절세가 되는지 알아보기 | 세금 혜택이 있는 계좌라는 점을 비유와 예시로 설명 | P9 (상품·제도 이해 어려움) |
| 내가 ISA를 써도 되는지 확인하기 | 가입 조건을 간단히 확인 | P9 (시작 금액·자산 비중 모름) |

제외한 후보: 적금과 ISA 차이 비교, ISA 유형 고르기(상품 선택에 가까워 중립성과 충돌 우려).

### 4단계 체크리스트 (확정): 소액 주식
| 항목 | 내용 | 근거 |
|---|---|---|
| 내 손실 한도 안에서 투자 금액 정하기 | 앞에서 정한 손실 한도를 넘지 않는 금액을 정함 | P5 (하락 시 손실 최소화 장치) |
| 하락했을 때 어떻게 할지 미리 정하기 | 손실이 났을 때의 대응 규칙을 미리 정함 | P5 (주가 변동 시 대응 방안 부족), P3 (불안으로 주식 상황 회피) |

제외한 후보: 가상 연습(MVP 범위 초과).

**손실 위험 안내 (확정)**: 4단계를 열기 전 필수 안내 화면
- "주식은 원금이 줄 수 있다"는 내용을 체크리스트 항목이 아니라, 단계가 열리기 전에 한 번 읽고 확인해야 넘어가는 화면으로 둡니다.
- 설계 원칙 "손실 위험은 숨기지 않고 먼저 알린다"를 지키는 장치입니다.
- 안내 문구의 구체 내용과 법적 검토는 미정입니다.

**행동 지원 방식 (확정)**: 단계별 화면 가이드 + 안전 안내
- 은행 앱에서 누를 화면 순서를 그림과 글로 설명합니다.
- "소액이라 부담 없고, 언제든 다시 꺼낼 수 있다"는 안전 안내를 함께 보여 줍니다.
- 특정 은행 앱으로 연결하거나 상품을 추천하지 않습니다. (중립성 유지)

MVP에서 제외하고 이후 후보로 남긴 기능: 상품 비교표, 소액 시드머니 플래너, 모의투자·연습 공간.

## 6. 다루는 상품 범위
안전 상품에서 주식까지 **단계적으로** 넓힙니다.
0. 용어·기초 익히기 (기초 용어, 내 한 달 돈 흐름 파악). 근거: P8 기초 경제 지식, P9 재테크 정보, P2 앱 시작 방법
1. 파킹통장 (원금 보장)
2. 적금 (원금 보장)
3. ISA 등 절세 상품
4. 소액 주식 (손실 가능성을 먼저 설명하고 연습 단계를 거침, 손실 한도 안에서만 열림)

원금 손실 불안(P3, P4, P10)이 큰 사용자를 먼저 안전 상품으로 시작시키고, 주식·코인 관심(P2, P3, P8, P9)은 뒤 단계에서 받아 줍니다.

## 6-1. 사용자 흐름
1. 접속 (회원가입 없음)
2. 한 화면에 한 질문씩 진단 3문항 (여유자금, 손실 불안, 수입 안정성)
3. 손실 한도 설정
4. 맞춤 로드맵(체크리스트) 확인 (현재 단계만 펼침)
5. 체크리스트 진행 중 어려운 용어는 눌러서 용어 사전으로 확인

회원가입 없이 바로 시작해서 진입 장벽을 낮추고, 한 화면 한 질문으로 결정 마비를 줄입니다. 

**진행 상황 저장 (확정)**: 기기에만 저장
- 진단 답, 손실 한도, 체크 상태를 사용자의 브라우저에 저장하고, 서버로 보내지 않습니다. 개인정보를 받지 않아 부담이 작고 MVP 범위에 맞습니다.
- 한계: 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다. 이 점을 사용자에게 미리 안내해야 합니다.
- 선택적 가입(여러 기기에서 이어쓰기)은 후속 버전 후보입니다.

## 7. 차별점
- 기존 금융 앱(토스, 카카오뱅크, 나무증권 등)은 상품 조회와 가입이 중심입니다. 인터뷰 응답자 중에도 주식 앱을 조회·확인 위주로 쓰는 경우가 있었습니다(P4 토스 증권 조회, P6 토스 주식 확인, P10 나무증권 앱 확인만 해봄).
- **차근차근은 가입 전 "무엇부터 할지"를 정해 주는 시작 전 단계에 집중합니다.**
- 보조 차별점 후보: 중립성(상품 판매 없음), 손실 한도 기반 안전장치

## 8. 설계 원칙
- 쉬운 말을 쓴다. 전문 용어는 풀어서 쓴다.
- 한 화면에 하나의 결정만 요청한다 (결정 마비 방지).
- 손실 위험은 숨기지 않고 먼저, 쉬운 말로 알려 준다.
- 특정 상품을 사라고 권유하지 않고 정보와 학습을 제공한다 (투자 권유 규제 이슈 회피, 추후 검토).

## 9. 성공 지표
- **진단 완료율 (확정)**: 시작 화면에서 진단 3문항을 끝까지 답한 사용자 비율. 한 화면 한 질문 구조가 결정 마비를 줄였는지 확인합니다.
- 참고: 진단 완료는 "시작"까지만 보여 주고 실제 행동(체크 완료)은 보여 주지 않습니다. 1단계 체크 완료율, 재방문율은 후속 지표 후보입니다.

## 10. 미정 항목
- 슬로건
- 손실 한도 재설정 방법, 4단계 필수 안내 화면의 문구
- 핵심 화면 구성(와이어프레임) 보완, 기록이 사라진다는 안내 문구와 위치
- 수익 모델 (사용자 검증 후 결정, 상품 판매 수수료는 중립성 때문에 신중히 검토), 경쟁 서비스 상세 비교
- 법적·규제 검토 범위
