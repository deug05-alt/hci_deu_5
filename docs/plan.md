# 서비스 기획서 (초안)

> 상태: 초안. 질문과 답변으로 하나씩 구체화하는 중입니다. `(미정)` 표시는 아직 결정하지 않은 항목입니다.

## 1. 서비스 개요
- **서비스명**: 차근차근
- **한 줄 정의**: 재테크를 시작하지 못하는 20대 사회초년생에게 쉬운 말로 단계별 시작 로드맵을 알려주는 맞춤 온보딩 가이드
- **형태**: 모바일 웹

## 2. 문제 정의 (인터뷰 P1~P10 근거)
공통 문제는 "시작을 못 함"입니다. 세 가지 원인이 겹칩니다.

| 원인 | 근거 응답자 | 대표 내용 |
|---|---|---|
| 여윳돈(시드머니) 부족 | P1, P2, P6, P8, P10 | 가장 먼저 해결할 문제로 "여윳돈 마련"을 꼽음 |
| 용어·정보의 어려움 | P2, P4, P5, P6, P8, P9, P10 | 어디서부터 해야 할지 모르고, 정보가 많아 고르기 어려움 |
| 원금 손실 불안 | P3, P4, P5, P10 | 안전성 확인 불가, 하락 시 대응 방안 부족 |

기존 대처 방식은 지인에게 묻기(P6, P7), 포털 검색(P10), 유튜브·SNS 탐색(P1, P2, P4)이었고, 결국 실행하지 못하고 미루는 경우가 많았습니다.

## 3. 타겟
- **주 타겟**: Type B 이길잡 (26세 사회초년생, 가이드 필요, 결정 마비)
  - 근거 응답자: P2, P5, P6, P8
- **보조 타겟**: Type A 김안전 (23세 대학생, 안전 지향, 직접 비교)
  - 근거 응답자: P4, P7, P9, P10
  - 로드맵 안의 상품 비교 단계에서 참고합니다.

## 4. 핵심 컨셉
**맞춤 온보딩 가이드.** 소득, 여윳돈, 손실 불안 정도를 묻고, 쉬운 용어로 단계별 시작 로드맵을 제안합니다.

## 5. MVP 기능
| 기능 | 설명 | 근거 |
|---|---|---|
| 진단 질문 + 맞춤 로드맵 | 소득, 여윳돈, 불안 정도를 묻고 나에게 맞는 단계별 시작 로드맵을 만든다 | P2(단계별 로드맵 가이드), P6, P8, P9 |
| 쉬운 용어 사전 | 본문 안의 어려운 금융 용어를 누르면 쉬운 말로 풀어 준다 | P4(복잡한 금융 용어), P5, P8(기초 경제 지식), P9 |

MVP에서 제외하고 이후 후보로 남긴 기능: 상품 비교표, 소액 시드머니 플래너, 모의투자·연습 공간.

## 6. 다루는 상품 범위
안전 상품에서 주식까지 **단계적으로** 넓힙니다.
1. 파킹통장, 적금 (원금 보장)
2. ISA 등 절세 상품
3. 소액 주식 (손실 가능성을 먼저 설명하고 연습 단계를 거침)

원금 손실 불안(P3, P4, P10)이 큰 사용자를 먼저 안전 상품으로 시작시키고, 주식·코인 관심(P2, P3, P8, P9)은 뒤 단계에서 받아 줍니다.

## 7. 설계 원칙
- 쉬운 말을 쓴다. 전문 용어는 풀어서 쓴다.
- 한 화면에 하나의 결정만 요청한다 (결정 마비 방지).
- 손실 위험은 숨기지 않고 먼저, 쉬운 말로 알려 준다.
- 특정 상품을 사라고 권유하지 않고 정보와 학습을 제공한다 (투자 권유 규제 이슈 회피, 추후 검토).

## 8. 미정 항목
- 슬로건
- 진단 질문 목록과 로드맵 단계 구성
- 핵심 화면 구성과 사용자 흐름
- 수익 모델, 경쟁 서비스 대비 차별점
- 성공 지표
- 법적·규제 검토 범위
